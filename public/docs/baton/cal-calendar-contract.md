# BATON CAL 일정 및 구독 계약

## 책임

CAL은 BATON이 확정한 시즌 일정과 마감을 읽기 전용 iCalendar(`.ics`) 피드로 제공합니다. BATON은 일정 한 건의 전체 현재 값과 개정 번호를 JSON으로 보내고, CAL은 같은 일정과 이전 번호가 다시 들어오는지 확인한 뒤 캘린더 형식으로 변환합니다. 어떤 일정을 포함하고 누가 구독할 수 있는지는 BATON이 결정합니다.

## 일정 및 구독 처리

-   이벤트 ID, 일정 ID, 개정 번호와 내용 해시를 비교해 적용, 중복, 이전 버전과 충돌을 구분합니다.
-   고정된 `UID`와 원본 개정 번호 기반 `SEQUENCE`로 변경 및 취소를 표현합니다.
-   같은 일정에서는 같은 `.ics`, `ETag`와 `Last-Modified`를 생성합니다. 캘린더 앱이 이전 ETag를 보내고 일정이 바뀌지 않았으면 본문 대신 `304 Not Modified`를 반환합니다.
-   구독 토큰은 한 번만 반환하고 DB에는 SHA-256 해시만 저장합니다.
-   토큰을 회전하거나 폐기하면 이전 구독 URL은 더 이상 피드를 반환하지 않습니다.

## 검증 기준

PostgreSQL Testcontainers와 `.ics` 기대값 파일로 같은 일정 재전송, 과거 및 충돌 개정 번호, 저장 데이터 기반 재생성, 서머타임 전환(DST)과 자정 경계, 취소 일정, UTF-8 줄 접기, 변경 없음 응답(`304 Not Modified`)과 구독 토큰 동시 회전을 확인했습니다.

안정 계약 1.0.0 기준으로 BATON 코드가 만든 실제 일정 JSON을 CAL 컨테이너에 보내 생성, 변경, 취소와 순서가 바뀐 전달이 올바르게 처리되는지도 별도로 확인했습니다.

## 현재 범위

시즌 일정의 수신, 변경, 취소와 BATON 일정 이벤트 JSON 호환성 검증을 완료했습니다. 운영 자격 증명으로 BATON의 전송을 활성화하고 공개 캘린더 앱에서 구독하는 과정, DB 복구 후 전체 일정 재전송 절차는 아직 운영 환경에서 실행하지 않았습니다.
