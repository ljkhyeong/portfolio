# BATON BRIEF 이벤트 중복 처리와 주간 보고서 생성

## 책임

BRIEF는 BATON 이벤트를 받아 담당자가 없는 역할, 담당 종료가 임박했지만 후임자가 없는 역할, 책임 목록과 바통 항목 및 역할 자료가 부족한 역할, 서로 다른 2개 이상 회차에서 마감 뒤에도 끝나지 않은 반복 업무, 다음 담당자가 정해졌지만 바통을 시작하지 않았거나 진행 조건이 남은 인수인계를 현재 확인 목록으로 만듭니다. 보고서를 만들 때 마지막으로 수락한 이벤트의 수신 순번과 포함 항목을 함께 저장하며, 이후 이벤트가 바뀌어도 생성한 보고서는 수정하지 않습니다.

## 중복 및 이전 버전 처리

-   이벤트 ID, 본문 해시와 개정 번호를 비교해 같은 이벤트 재전달, 같은 ID의 다른 내용, 과거 개정 번호와 번호가 건너뛴 이벤트를 구분합니다.
-   수락한 이벤트 기록과 현재 확인 목록을 같은 PostgreSQL 트랜잭션에서 저장합니다.
-   저장한 이벤트 전체를 다시 읽어 기존 현재 확인 목록을 한 트랜잭션에서 교체할 수 있습니다.
-   같은 주간, 같은 마지막 수신 순번과 같은 항목으로 생성하면 기존 보고서를 반환합니다. 이후 상태가 바뀌었다가 같아진 경우에는 새 생성 번호로 별도 보고서를 저장합니다.
-   전용 Bearer는 현재 값과 직전 값을 잠시 함께 허용해 중단 없이 교체합니다.

## 테스트 기준

PostgreSQL 통합 테스트로 이벤트 중복, ID 충돌, 지원하지 않는 버전, 과거 및 건너뛴 개정 번호, 현재 목록 전체 재생성과 동일 보고서 중복 생성을 확인했습니다. 로컬에서는 BATON 실행 JAR가 보낸 실제 이벤트를 Caddy 내부 인증서 기반 HTTPS로 BRIEF 실행 JAR가 수신하고, 기존 Bearer와 새 Bearer를 잠시 함께 허용해 전송 중단 없이 토큰을 교체하는 과정도 확인했습니다.

## 현재 범위

최신 구현은 로컬 개발 브랜치에 있으며 공개 저장소의 `main`은 아직 초기 스캐폴드입니다. 공인 DNS 및 ACME 인증서와 실제 두 스테이징 호스트 사이의 원격 전달 및 장기 운영 배포는 아직 검증하지 않았습니다.
