# BATON BRIEF 관심 항목 투영과 불변 에디션

## 책임

BRIEF는 BATON의 다섯 연속성 신호를 설명 가능한 현재 관심 항목으로 투영합니다. 특정 주간과 생성 커서의 상태는 불변 에디션으로 고정하며 이후 현재 투영이 바뀌어도 기존 에디션을 수정하지 않습니다.

## 중복 및 이전 버전 처리

-   이벤트 ID, 본문 지문과 집계 개정 번호로 재전달, 식별자 충돌, 이전 전달과 개정 공백을 구분합니다.
-   수신 증거와 현재 관심 항목은 같은 PostgreSQL 트랜잭션에서 반영합니다.
-   저장한 수신 이력으로 현재 관심 항목을 원자적으로 다시 만들 수 있습니다.
-   주간 범위, 생성 커서와 상태가 같으면 기존 에디션을 재사용하고, 과거와 같은 상태로 돌아와도 새 세대로 이력을 남깁니다.
-   전용 Bearer는 현재 값과 직전 값을 잠시 함께 허용해 중단 없이 교체합니다.

## 테스트 기준

PostgreSQL 통합 시나리오로 중복, 충돌, 지원하지 않는 버전, 이전 개정 번호, 개정 공백, 전체 재구축과 에디션 멱등 생성을 확인했습니다. 로컬에서는 BATON 실행 JAR가 보낸 실제 이벤트와 BRIEF 실행 JAR의 수신, 전용 Bearer 교체와 Caddy 내부 CA HTTPS 경계까지 교차 검증했습니다.

## 현재 범위

최신 구현은 로컬 개발 브랜치에 있으며 공개 저장소의 `main`은 아직 초기 스캐폴드입니다. 공인 DNS 및 ACME 인증서와 실제 두 스테이징 호스트 사이의 원격 전달 및 장기 운영 배포는 아직 검증하지 않았습니다.
