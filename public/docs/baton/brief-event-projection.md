# BATON BRIEF 이벤트 처리와 주간 브리프 생성

## 책임

BRIEF는 BATON의 인수인계 지연, 루틴 누락과 결정 후속 조치 지연 이벤트를 받아 사용자가 확인할 항목으로 정리합니다. 생성한 주간 브리프는 이후 조회 데이터가 바뀌어도 수정하지 않습니다.

## 중복 및 이전 버전 처리

-   이벤트 ID와 내용 해시로 같은 이벤트 재전달과 식별자 충돌을 구분합니다.
-   원본 개정 번호를 비교해 이전 버전 이벤트가 현재 항목을 덮지 못하게 합니다.
-   수신 이력과 조회용 데이터는 같은 PostgreSQL 트랜잭션에서 반영합니다.
-   저장한 수신 이력으로 조회 데이터를 다시 만들 수 있습니다.

## 테스트 기준

MockMvc와 PostgreSQL Testcontainers로 중복, 충돌, 지원하지 않는 버전, 이전 개정 번호, 개정 번호 누락과 동시 요청을 확인했습니다. 같은 이벤트를 동시에 보내도 수신 기록은 1건, 같은 상태로 주간 브리프를 동시에 생성해도 결과는 1건만 저장됩니다.

## 현재 범위

로컬 MVP와 통합 테스트까지 구현했습니다. BATON Core 이벤트 연동, 인증 및 운영 환경 배포는 아직 하지 않았습니다. 공개 저장소에는 최신 로컬 MVP가 아직 동기화되지 않았습니다.
