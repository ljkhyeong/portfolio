# 포트폴리오 문구 간결화 — 2026-11-10

## 범위와 기준

사용자 요청으로 홈, 프로젝트 상세, BATON 서비스, 도식, 검색, 인쇄 17개 경로의 문구를 수집했다. 접힌 설명과 이미지 설명도 포함했다. 공유 이미지와 경로 메타는 원본 데이터에서 별도로 확인했다. 기존 메인 제목, 실무 용어, 수치와 검증 범위는 유지하고 새 성과는 추가하지 않았다.

참고한 개인 사이트는 [Brittany Chiang](https://brittanychiang.com/), [Lee Robinson](https://leerob.com/), [Josh W. Comeau](https://www.joshwcomeau.com/)다. Brittany의 용도 중심 프로젝트 소개와 별도 기술 목록, Lee의 짧은 소개를 참고했다. Josh의 홈은 기술 글 중심이라 프로젝트 소개 구조에 직접 적용하지 않았다. 문장이나 디자인을 복제하지 않았다.

## 반영

-   홈: 현재 업무를 먼저 소개하고 긴 기능 나열을 줄였다. 카드 소개와 대표 구현(`homeSummary`, `homeStory`) 12개 문구의 총 글자 수는 1,376자에서 1,072자로 약 22% 줄었다. 상세에는 담당 기관과 개별 서비스 기능을 유지했다.
-   상세: 긴 제목에서 세부 조건을 덜어내고 본문에 남겼다. 문제와 아키텍처 제목 68개의 총 글자 수는 1,722자에서 1,432자로 약 17% 줄었다. 중복 저장, 응답 유실, 순서 역전처럼 구체적인 문제를 제목에 썼다.
-   검증 안내: 구현 설명과 반복 표현을 줄이고, 공개 main, 로컬 검증, 운영 미검증을 구분했다. Hope 원작자 고지, 전자영장 부하 조건과 시연 환경의 HLS 수치는 유지했다.
-   검색: 첫 화면은 문서 검색과 원문 확인을 안내한다. RAG 처리 방식은 기존 도식에 남겼고, 공개 사이트가 브라우저 검색만 제공한다는 안내를 앞세웠다.
-   메타와 공유 이미지: 상세와 같은 의미로 맞췄다. README 소개, 검색 자료, OG와 PDF도 갱신했다.

## 검증

전체 화면 17개 경로를 1440px와 390px에서 검사해 34건이 통과했다. PDF는 4쪽을 유지했다. 문구에 결합된 기존 테스트 기대값과 검색 평가의 대상 제목만 새 제목에 맞췄으며 질문과 판정 기준은 바꾸지 않았다.

브라우저 검색은 24/24건이 상위 5건에 들었다. 제목 축약 후 순위가 바뀌어 MRR@5는 0.903에서 0.802로 낮아졌다. 화면에 표시한 브라우저 평가값도 갱신했다. 서버의 이전 CI 결과는 날짜와 함께 별도로 유지했다. 최종 테스트와 빌드, 직접 확인한 캡처는 `output/validation/last-run.md`에 기록한다.
