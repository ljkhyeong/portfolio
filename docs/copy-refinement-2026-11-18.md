# 포트폴리오 압축과 성과 강조 검토

기준 리비전은 `23ad050`이다. 사용자가 제시한 팀 구성 설명 축소, 풀스택 직무명, 성과 강조와 개선율, AI 도구 언급 정리 기준으로 홈, 상세, 연표, 기술, 검색 메타, 공유 이미지, 인쇄 원문과 공개 요약 문서를 검토했다. 기존 17개 경로의 렌더링 구조와 텍스트 수집본을 참조했다. 이번 결과는 수정 제안이며 새 브라우저 검사나 프로젝트 성과 측정은 실행하지 않았다.

## 성과 강조 후보

| 프로젝트       | 굵게 표시할 핵심                                     | 수치 처리                                                                                                   |
| -------------- | ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 전자영장       | **이중화 서버의 배치 중복 실행 방지**                | 100 RPS·300 TPS, 1시간은 상세의 부하 테스트 조건으로 유지한다. 개선 전 수치가 없어 개선율을 계산할 수 없다. |
| 군사법         | **배치 장애 원인 추적과 군교정 DB 반영 복구**        | 장애 횟수나 복구 시간의 전후 측정 자료가 없다.                                                              |
| BATON          | **중복 이벤트의 전송 작업 생성 방지**                | 링크 생성과 이벤트 수신의 처리 대상을 각각 명시한다.                                                        |
| happyGallery   | **결제 응답 유실 시 중복 승인과 환불 방지**          | 모의 결제사 응답을 사용한 통합 테스트 범위를 함께 표시한다.                                                 |
| WebRTC/HLS     | **HLS 재생 지연 약 51% 감소**                        | `(35 - 17) / 35 × 100 = 51.43%`. 원본 값이 근삿값이므로 약 51%로 표현한다. 팀 시연 조건을 붙인다.           |
| 청년정책메이트 | **확인할 수 없는 신청 조건은 추가 확인 필요로 안내** | 정책 15건은 적용 범위다. 성공률로 변환하지 않는다.                                                          |
| Hope Commit    | **리뷰 항목과 실제 변경 코드 연결**                  | 공개 릴리스와 코드 근거 검사를 설명한다. 생산성 향상률은 측정하지 않았다.                                   |
| IntentTrace    | **코드 변경 이유와 검증 결과를 커밋 단위로 추적**    | 구현 및 자동화 검증 범위를 유지한다. 개발 시간 단축률은 측정하지 않았다.                                    |

AWS 비용 분석, OFFSET 조회 개선, GO SQL 개선에도 전후 비교 수치가 없어 퍼센트를 추가할 근거가 없다. 공개 요약의 요청당 약 10초는 토스 기술 블로그의 측정값이다. 개인 프로젝트 성과에 사용하지 않는다.

## 적용 시 주의할 위치

현재 React 컴포넌트는 데이터 문자열을 일반 텍스트로 출력한다. 문자열에 Markdown 별표를 넣으면 별표가 그대로 나타난다. 승인된 강조 구절을 데이터로 지정하고 홈·상세·인쇄에서 `<strong>`으로 렌더링해야 한다. 검색 메타에는 일반 텍스트를 쓰고 OG는 이미지 레이아웃에서 강조한다.

‘6명’은 교육 프로젝트 인원 외에도 ROUND 최대 참가자 수와 장시간 접속 검증 범위에 사용한다. 팀 구성 설명을 제거할 때 기능 제한까지 지우지 않는다. IntentTrace의 Codex 연동 문서와 공개 요약의 훅 명칭은 실제 연동 대상을 설명하므로 구체적인 이름을 유지한다. Hope Commit과 IntentTrace의 AI 리뷰·변경 기록은 제품 기능이므로 소개에 남긴다.

본 검토는 문서만 변경했다. 실제 반영 시 공통 데이터, 메타, README, 검색 자료, OG와 PDF를 함께 갱신하고 모바일 줄바꿈, 강조 개수와 검색 평가를 확인한다.
