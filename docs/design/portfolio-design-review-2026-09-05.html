먼저 바꿀 다섯 가지

  1. 실명과 직무를 첫 화면에 표시

  3. 프로젝트마다 문제, 구현, 검증 범위를 짧게 표시
  4. 큰 서비스 이미지와 모바일 처리 도식의 높이 축소
