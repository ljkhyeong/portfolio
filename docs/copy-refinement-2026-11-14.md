# 포트폴리오 문구 재검토

배포 기준 `11c11a4`. 홈, 프로젝트 상세, BATON 서비스, 검색과 인쇄를 포함한 17개 경로의 기존 화면 수집본과 현재 원본 데이터를 대조했다. 검토 기준은 처음 읽는 사람이 담당 업무, 해결한 문제, 검증 범위를 구분할 수 있는지다. 이번 검토는 표현의 정확성에 한정하며 운영 상태는 지난 현행화에서 확인한 리비전을 기준으로 한다.
