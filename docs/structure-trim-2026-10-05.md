## 유지한 것

-   소개의 요청 처리 흐름 4단계: 첫 화면에서 핵심 역량을 한 줄로 보여 주는 유일한 요약이다.
-   GitHub 기여 기록, 상세 화면 캡처, 도식, 구현 방법, 대표 문서 목록과 사용 기술: 다른 영역에 같은 정보가 없다.
-   모든 수치, 커밋, 버전과 검증 범위 구분. 새 성과나 수치는 추가하지 않았다.

## 인쇄 쪽 나눔

-   경력 영역 전체에 걸린 나눔 금지를 행 단위로 바꿨다. 경력 행에 문제·구현·검증이 들어가 영역이 길어지면서 첫 쪽 아래가 비었다.
-   프로젝트를 새 쪽에서 시작하던 강제 나눔을 없앴다. 경력 아래 남은 공간이 반 쪽 가까이 비었다.
-   제목 뒤 나눔 금지를 본문이 이어지는 제목에만 적용한다. 행의 마지막 요소이거나 그리드 항목인 제목에서는 이 값이 행 끝까지 전파되어, 학습 행과 기술 묶음 사이에서 쪽을 나눌 수 없었고 남은 공간이 있어도 영역 전체가 다음 쪽으로 넘어갔다.
