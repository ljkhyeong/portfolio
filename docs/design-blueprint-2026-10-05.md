# 도면형 메인과 검증 단계 레일 적용 — 2026-10-05

## 판단

참고 포트폴리오 후보 D·E·F([시안](design/portfolio-design-candidates-2-2026-10-05.html))와 이전 후보 A·B·C([시안](design/portfolio-design-candidates-2026-10-05.html))를 비교한 뒤, 사용자가 D(도면형)를 메인으로 고르고 C의 검증 단계 레일을 프로젝트 상세에 두기로 했다. D는 `ncdai/chanhdai.com`의 가는 기준선, Fig. 번호가 붙은 그림, 기여 히트맵을 참고했다. 원본 그림과 로고는 쓰지 않고 이 저장소의 데이터로 다시 그렸다.

읽는 순서(이름과 직무 → 경력 → 대표 프로젝트 → 기타 프로젝트)는 바꾸지 않았다. 구조도와 히트맵은 첫 화면의 장식이 아니라 BATON 구성과 최근 개발 활동이라는 정보를 담는 그림으로 둔다.

## 산출물

-   홈 공유 이미지는 이전처럼 1200×630 첫 화면을 그대로 찍는다. 이제 상단 바(이름·직무)와 Fig. 1이 보이고, 아래쪽에 소개 영역 일부가 걸린다. 헤드리스 Chrome의 `--screenshot`은 `#top` 이동 뒤 합성이 깨져 소개 영역으로 맞추지 않았다.
-   PDF는 10쪽에서 11쪽이 됐다. 1쪽에 소개, 처리 흐름, 기본 정보와 기여 기록이 들어가고 2쪽이 경력이다.
-   새 컴포넌트와 CSS가 산출물 지문 입력에서 빠져 PDF가 최신으로 잘못 판정되는 문제가 있었다. 입력 목록에 추가하고, 홈과 PDF 진입 파일의 import를 따라가 누락을 잡는 테스트를 넣었다.

## 남은 항목

-   기여 기록은 갱신 명령을 실행해야 바뀐다. 자동 갱신 작업은 두지 않았다.
-   700px 이하의 기여 기록은 최근 21주만 보여 준다. 제목과 합계는 1년 기준이며 월 라벨로 표시 범위를 알 수 있다.
