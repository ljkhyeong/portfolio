# 전자영장 통신사 연계 반영 — 2026-11-18

## 확인한 기준

사용자가 제공한 담당 업무와 진행 상태를 반영했다. 비공개 저장소는 대상 프로젝트 확인에만 사용했으며, 내부 코드와 문서, 테이블명, 접속 정보는 공개 자료에 옮기지 않았다.

-   기존 3통신사 연계: EAI 연계 서버를 통한 SFTP 송수신. 업무 DB 요청정보로 XML 생성, 회신 XML 파싱과 업무 테이블 갱신, 회신 파일 압축 해제와 업로드 구현.
-   별정통신사 추가 연계: 개발 완료 후 통신사와 테스트 중. 2026년 11월 27일 오픈 예정.
-   기존 시스템의 2026년 9월 28일 개통 및 운영 상태는 유지했다. 추가 연계를 운영 완료로 표기하지 않았다.

## 반영 범위

홈 요약, 상세 담당 역할과 구현 사례, 추가 개발 상태, 공유 이미지 문구, 검색 메타 설명과 README를 갱신했다. 기존 기관 연계 도식은 유지하고 3통신사 EAI/SFTP 흐름은 담당 구현 영역에서 설명했다.

개발 완료와 테스트 진행 상태는 사용자 제공 결과다. 회사 시스템의 테스트를 직접 실행하지 않았다. 비공개 업무 화면은 촬영하지 않았다. 포트폴리오의 데스크톱과 모바일 화면, PDF 및 공유 이미지를 확인한다.

## 후속 보완

사용자 정정에 따라 집행포털과 전자영장 시스템은 동일한 시스템으로 설명하고, 화면과 도식은 전자영장 시스템으로 통일했다.

별정통신사 추가 개발을 상태 안내에만 두지 않고 문제 해결과 분리된 담당 구현 영역에 추가했다. 통신사별 발송 단위, EAI를 통한 파일 전송과 API 호출 분리, 요청 파일 완성 후 송신 경로 이동, 화면에서 요청서 전체 또는 대상별 재처리가 대상이다. 응답 및 결과 파일 수집은 별도 배치 담당 범위로 명시했다. 사용자가 확인을 요청한 저장소에서 기능 범위를 대조했으며 내부 코드, 식별자와 연계 규격은 옮기지 않았다.

전체 프로젝트 상세 8개와 BATON 서비스 상세 6개의 본문에 강조를 연결했다. 핵심 구현과 검증 결과만 선택해 굵게 표시하며, 본문과 검색 자료의 원문은 보존한다. HLS는 기존 제공 수치인 약 51% 감소와 약 35초 → 약 17초, 팀 시연 환경을 함께 표시한다. 전후 측정값이 없는 프로젝트에는 개선율을 만들지 않는다.
