# 전자영장 통신사 연계 반영 — 2026-11-18

## 확인한 기준

사용자가 제공한 담당 업무와 진행 상태를 반영했다. 비공개 저장소는 대상 프로젝트 확인에만 사용했으며, 내부 코드와 문서, 테이블명, 접속 정보는 공개 자료에 옮기지 않았다.

-   기존 3통신사 연계: EAI 연계 서버를 통한 SFTP 송수신. 업무 DB 요청정보로 XML 생성, 회신 XML 파싱과 업무 테이블 갱신, 회신 파일 압축 해제와 업로드 구현.
-   별정통신사 추가 연계: 개발 완료 후 통신사와 테스트 중. 2026년 11월 27일 오픈 예정.
-   기존 시스템의 2026년 9월 28일 개통 및 운영 상태는 유지했다. 추가 연계를 운영 완료로 표기하지 않았다.

## 반영 범위

홈 요약, 상세 담당 역할과 구현 사례, 추가 개발 상태, 공유 이미지 문구, 검색 메타 설명과 README를 갱신했다. 기존 기관 연계 도식은 유지하고 3통신사 EAI/SFTP 흐름은 별도 구현 사례로 설명했다.

개발 완료와 테스트 진행 상태는 사용자 제공 결과다. 회사 시스템의 테스트를 직접 실행하지 않았다. 비공개 업무 화면은 촬영하지 않았다. 포트폴리오의 데스크톱과 모바일 화면, PDF 및 공유 이미지를 확인한다.
