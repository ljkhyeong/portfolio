## 수정 기준

-   `인계`, `시도 정보`, `운영 작업자`처럼 대상을 바로 알기 어려운 말은 실제 처리 동작으로 바꿨다.
-   `heartbeat`, `payload`, `callback`은 각각 `처리 기한 갱신`, `요청 본문`, `Core 콜백`으로 풀어 썼다.
-   `N → P`, `완료 → null`은 `처리대상(N) → 처리 중(P)`, `완료 후 처리 상태 초기화`로 설명했다.
-   한 문장에 구현·검증·제약을 함께 넣은 경우 문장을 나누고, 같은 의미가 반복되면 줄였다.
-   GitHub에서 확인한 현재 공개 범위에 맞춰 Core·GO·RELAY·ROUND는 비공개 구현, WATCH·BRIEF·CAL은 공개 저장소로 구분했다.
