# 근거 문서 형식

`docs/project-progress-YYYY-MM-DD.md`에 아래 형식으로 남긴다. 다음 현행화에서 이 문서의 확인 리비전부터 변경을 확인한다. 공개 저장소에 포함되므로 비공개 저장소의 내부 경로, 토큰과 개인정보는 적지 않는다.

```markdown
# 프로젝트 현행화 근거 — YYYY-MM-DD

각 프로젝트의 로컬 저장소, 공개 브랜치, README·PRD·ADR·운영 문서와 최근 커밋을 대조했다. 구현 완료, 로컬 검증과 실제 외부 운영은 구분해 반영했다. 다른 저장소의 제품 코드는 수정하지 않았다.

## 확인한 기준

| 프로젝트               | 확인 리비전                           | 반영 내용 |
| ---------------------- | ------------------------------------- | --------- |
| BATON Core (`manager`) | 공개 `main` `abcdef12`                | …         |
| 청년정책메이트         | 공개 `main` `1b7fbdd`, 로컬 `6f33f72` | …         |

로컬 브랜치 기준 내용, 확인 중 원격에 병합돼 다시 대조한 항목, 새 근거가 없어 유지한 프로젝트를 적는다.

## 다이어그램

-   바꾼 도식과 이유. 기존 색상, 글꼴, 노드 간격과 직교 연결선 유지 여부.

## 스크린샷

| 대상 | 교체·추가 화면 | 촬영 기준                                    |
| ---- | -------------- | -------------------------------------------- |
| …    | …              | 실행 환경, 데이터 출처, 화면 크기와 브라우저 |

## 검증 범위 해석

-   로컬·임시 환경 검증과 실제 외부 연동을 구분한 항목.
-   모의 응답이나 통합 테스트 데이터로 촬영한 화면.

포트폴리오의 테스트, 산출물 생성과 최종 빌드 결과는 `output/validation/last-run.md`에 기록한다.
```
